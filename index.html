  2. Enable Firestore Database (Choose Test Mode).
  3. Enable Authentication (Enable the Email/Password sign-in method).
  4. Go to Project Settings, add a Web App (</>), and copy the firebaseConfig variables.
  5. Open this code in Vercel or your editor, and paste the values into the manualConfig variable at the bottom of the file (around line 830).
